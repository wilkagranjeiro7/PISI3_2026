# Dataset local

O dataset não é versionado no Git. Coloque o arquivo obtido na fonte original em uma destas localizações:

- `Dashboard/whoop_fitness_dataset_100k.xlsx`;
- `whoop_fitness_dataset_100k.xlsx` na raiz do projeto;
- `Dashboard/data/dataset.xlsx`;
- `Dashboard/data/dataset.parquet`.

Após a primeira leitura, o cache `Dashboard/data/dataset.pkl` será criado automaticamente.
